Vidu API 配置教程

💰 约 ¥0.36/秒 · 动作同步 · 稳定可靠
1注册Vidu账号

访问Vidu开放平台，使用邮箱或Google账号注册。

🔗 前往Vidu开放平台
2充值算力额度

登录后，在账户中心充值API Credits（算力额度）。新用户通常有免费试用额度。

💡 建议先充值少量额度测试，确认效果后再按需充值。
3创建API Key

进入「API Keys」标签页，点击「Create API Key」创建新的密钥。

创建后立即复制保存（密钥只显示一次）。

⚠️ API Key是你的支付凭证，请勿泄露给他人！
4配置到平台

打开AI舞蹈模仿平台，选择「Vidu」模型。

在「Vidu接口密钥」输入框中粘贴你的API Key，点击保存。

API Key格式： sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
5测试生成

上传人物图 + 参考视频，点击「一键生成」测试。

如果报错「Invalid API Key」，请检查密钥是否复制完整、是否有多余空格。

可灵 API 配置教程

💰 2.6版 ¥0.5/秒 · 3.0版 ¥0.9/秒 · 动作控制
1注册可灵账号

访问可灵AI开放平台，使用手机号注册。

🔗 前往可灵开放平台
2开通API服务

登录后，进入「开放平台」或「API管理」页面，开通API调用服务。

购买资源包或开通按量计费（必须有额度才能调用）。

💡 可灵API和网页端会员额度不通用，需要单独充值API额度。
3创建API Key

进入「API管理」→「新建API Key」。

创建后密钥仅显示一次，立即复制保存。

⚠️ 可灵使用AK/SK生成JWT Token鉴权，平台已自动处理，你只需填入API Key即可。
4配置到平台

打开平台，选择「可灵2.6」或「可灵3.0」模型。

在「可灵API密钥」输入框中粘贴API Key。

API Key格式： xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
5测试生成

上传素材，点击「一键生成」。

可灵生成时间较长（通常1-3分钟），请耐心等待。

Agnes API 配置教程

💰 约 ¥0.36/秒 · 支持分辨率选择 · 视频参考生成
1注册Agnes账号

访问Agnes AI平台，使用邮箱注册。

🔗 前往Agnes平台
2充值额度

登录后，在账户中心充值API调用额度。

💡 Agnes支持480P/720P/1080P分辨率选择，分辨率越高费用越高。
3获取API Key

进入「API设置」或「开发者」页面，创建API Key。

复制保存你的API Key。

4配置到平台

打开平台，选择「Agnes 2.5」模型。

在「Agnes API Key」输入框中粘贴密钥。

选择输出分辨率（480P/720P/1080P）。

API Key格式： sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
5测试生成

上传素材，点击「一键生成」。

❌ 常见错误「input audio or video is invalid or unsupported」：通常是视频链接无法访问，建议使用视频URL方式（粘贴直链），或切换其他模型。

万相 wan2.2-animate-move 配置教程

💰 约 ¥0.5/秒 · 阿里云出品 · 支持480P/720P/1080P · 无需代理
1注册阿里云百炼账号

访问阿里云百炼（Model Studio）控制台，使用阿里云账号登录。没有阿里云账号可先注册。

🔗 前往阿里云百炼控制台
💡 注意：旧版 dashscope.console.aliyun.com 已于2026年8月下线，请使用新的 bailian.console.aliyun.com。
2开通模型服务

登录后，在「模型广场」或「视频生成」分类中找到「万相-图生动作（wan2.2-animate-move）」。

点击「开通服务」或「立即体验」，按照提示完成开通（可能需要实名认证）。

⚠️ 新用户通常有免费试用额度，可先免费测试效果。
3获取API Key

在控制台左侧菜单找到「API Key管理」或点击右上角头像 →「API Key」。

点击「创建新的API Key」，输入名称后确认创建。

创建后立即复制保存（密钥只显示一次，格式为 sk- 开头）。

API Key格式： sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
❌ API Key是你的支付凭证，请勿泄露给他人！丢失后请立即删除并重新创建。
4充值算力额度

在「费用中心」或「资源包管理」中充值或购买算力资源包。

万相图生动作按生成视频秒数计费，标准模式（wan-std）约¥0.5/秒。

💡 调用失败不产生费用，也不消耗免费额度。建议先充值少量测试。
5配置到平台

打开AI舞蹈模仿平台，选择「🌀 万相 2.2」模型。

在「DashScope API Key」输入框中粘贴你的API Key（自动保存到本地）。

选择输出分辨率（480P/720P/1080P）和视频时长（2-15秒）。

6测试生成

上传人物图片 + 参考舞蹈视频（或粘贴视频URL直链），点击「一键生成」。

万相模型支持CORS跨域，不需要代理，国内网络可直接调用。

💡 生成视频URL有效期24小时，请及时下载保存到本地。
❌ 常见错误「InvalidApiKey」：检查密钥是否复制完整、是否有多余空格、是否已开通万相模型服务。
7效果优化建议

📌 人物图与参考视频人物身材比例尽量一致，输出效果更好。

📌 建议上传竖版人物图片，输出分辨率跟随人物图比例。

📌 使用高清、高帧率参考视频可提升生成画质。

📌 标准模式（wan-std）生成快、性价比高；专业模式（wan-pro）效果更好但更慢更贵。

常见问题 FAQ

配置失败？生成报错？看这里！
Q：API Key配置后还是不能用？
A：请检查：①密钥是否复制完整（没有多余空格）；②账户是否有余额/额度；③是否开通了对应模型的API服务；④网络是否正常。
Q：哪个模型最便宜？
A：Vidu和Agnes都是约¥0.36/秒，是目前最便宜的。可灵2.6 ¥0.5/秒，万相¥0.5/秒，可灵3.0 ¥0.9/秒。
Q：生成10秒视频大概多少钱？
A：按单价计算：Vidu/Agnes约¥3.6，可灵2.6/万相约¥5，可灵3.0约¥9。实际费用以模型官方计费为准。
Q：上传视频失败怎么办？
A：建议：①改用「视频URL」方式，直接粘贴视频直链（最稳定）；②压缩视频到20MB以内；③切换WiFi/流量重试；④用电脑端操作。
Q：视频URL支持哪些链接？
A：支持以http://或https://开头的视频直链（.mp4/.mov等）。抖音/快手/B站等平台链接需要先解析成直链，部分平台可能因跨域限制无法解析。
Q：生成很慢/排队很久？
A：AI视频生成通常需要1-5分钟，高峰期可能排队更久。建议：①选择480P分辨率（生成最快）；②避开高峰期；③切换其他模型试试。
Q：生成的视频怎么保存？
A：手机端：长按视频 → 保存到相册。电脑端：右键视频 → 视频另存为。也可以点击「下载视频」按钮直接下载。
Q：API Key会泄露吗？安全吗？
A：API Key只保存在你自己的浏览器本地（localStorage），不会上传到任何服务器。清除浏览器数据会丢失配置，需要重新填写。请勿在公共设备上配置。
Q：可以同时配置多个模型吗？
A：可以！每个模型的API密钥独立保存，切换模型时自动使用对应密钥。建议至少配置2个模型，一个失败时可以切换另一个。
Q：新用户有免费额度吗？
A：大部分平台新用户都有免费试用额度：Vidu、可灵、Agnes、万相（阿里云百炼）都有新用户免费额度，可以先免费测试效果再决定充值。
